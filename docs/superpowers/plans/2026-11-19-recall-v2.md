# Signalpost recall v2 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise honest external recall for the Signalpost submission by publishing real role cards, deeper news, and a proven second platform for directory-only companies — without lowering entity precision (currently 1.0).

**Architecture:** Three new/changed connectors feed the existing observation corpus. Every new observation carries an explicit identity proof that the verifier re-derives from frozen evidence: `website_identity_gate` (company site), `registry_sole_declarer_domain_match` (register-declared domain + body corroboration, checked against the sole-declarer index), and `organisation_number_on_official_api` (GLEIF). The pipeline wires the new connectors, the merge tag list, and the official run command; then one fresh full run rebuilds every artifact and re-measures.

**Tech Stack:** Python 3.12 (`uv run`), `unittest`, `beautifulsoup4`/`lxml`, `extruct` (JSON-LD), stdlib `urllib`. No new dependencies, no API keys, $0 external cost.

**Spec:** `docs/superpowers/specs/2026-11-19-recall-v2.md`

## Global Constraints

- Keyless only: no API key, login, paid account. External cost per official batch stays **$0**.
- Entity precision ≥ 0.99 and **0** wrong-company publications; the verifier is fail-safe (an observation that cannot be re-derived from frozen evidence stays unpublished).
- A careers page is **not** a role card: publish `job_posting` only with a role title **and** an apply action **and** identity proof.
- Headcount is not hiring; `workforce_snapshot` stays outside the six-field proxy.
- Every observation carries source URL, retrieval time, `observed_at` when a date exists, `content_sha256`, `acquisition_mode`, `rights_status` and an `identity_proof` list.
- Determinism: same input → byte-identical output (sort by URL, fixed caps, no wall-clock in IDs).
- `out/` is gitignored; the promoted package needs explicit `git add -f` per file — never `git add -A` at repo root.
- Test command (run from `norhound-starter-kit/`): `uv run python -m unittest discover -s tests`.

## Review Focus

- A role page on a **group** site that lists another entity's vacancy → must not publish for the wrong organisation number.
- A careers page stating **"vi har ingen ledige stillinger"** → must not become a job posting.
- A **parked** domain (`www.example.no is parked`, "til salgs") → must not become a company website.
- A sitemap URL on a **different host** than the verified site → must not become a news claim.
- A `mailto:` apply link and a `#anchor` apply form → count as apply actions only under the rules in the spec; a plain `#` link does not.
